# Technical Support Subcommittee

## Purpose
This subcommittee is responsible for identifying, provisioning, and confirming all technical resources needed by participating teams — including cloud computing, virtual machines, GPU resources, GitHub repositories, and the event Slack workspace. It also ensures institutional IT compliance and serves as the technical escalation point during the event.

## Responsibilities

* Assess GPU and compute needs for all teams
* Coordinate setup of cloud resources, virtual machines, and development environments
* Coordinate the creation of GitHub repositories for all teams with onboarding subcommittee
* Open and manage the event Slack workspace
* Oversee access provisioning and tool setup for all participants
* Ensure cybersecurity standards and institutional IT policies are followed
* Confirm compliance with all IT approvals and procedures
* Confirm full technical readiness before event launch
* Serve as technical support escalation point during the event

## Success Metrics

* All teams technically ready at event start (September 16)
* All required approvals and access provisioning completed before launch
* Minimal technical escalations or blockers during the event

### Out of Scope

* Providing post-event production support for teams
* Writing or debugging participants' project code
